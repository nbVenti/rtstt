<h1> rtstt </h1>
</div>

Real Time Subtitle & Translation or rtstt for short, is a small scale project meant to help your viewing experience of entertainment in a different languages. It is designed to be resource friendly so it can be run locally without much cost on the system. It first records small chunks of audio and saves them locally, it then transcribes the audio clips into text, after a successful transcription, it translates the text into any given language.
